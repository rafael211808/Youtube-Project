# 🌐 HTML & CSS Course - Beginner to Pro

---

## 📌 About the Repository

This repository serves as a record of my ongoing learning regarding the fundamentals of front-end web development. All the code was written using **Visual Studio Code (VS Code)**, covering everything from basic structuring with HTML5 tags to modern CSS styling techniques.

---

## 🚀 Content Developed

- **HTML5 Structuring:** Basic semantics, paragraphs, headings, links, images, and buttons.
- **CSS Styling:**
- Font manipulation (integration with Google Fonts). 
- Colors, borders, shadows (`box-shadow`), and rounded corners (`border-radius`). 
- Hover effects, transitions, and interactive states (`:hover`, `:active`).
- **Box Model:** Margins, padding, element sizing, and borders.
- **Layout & Positioning:** Alignment, grid/flexbox structures, and page positioning concepts.
- **Practical Components:** Recreation of stylized buttons (e.g., styles from Amazon, YouTube, Twitter), product cards, and promotional pages.

## 🛠️ Technologies Used

- **HTML5** (Markup Language)
- **CSS3** (Styling for Pages and Components)
- **Visual Studio Code** (Code Editor / Development Environment / IDE)
